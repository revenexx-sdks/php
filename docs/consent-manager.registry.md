# ConsentManagerRegistry Service


```http request
GET https://api.revenexx.com/v1/consent-manager/catalog
```

** The vendor catalogue this version of the app ships — the vendors met in B2B shops, each with company, purposes, hosts and cookies in German and English — and, per entry, whether this tenant adopted it and whether the copy is older. `?category=` narrows it to one group (analytics, advertising, chat, external_media, …). **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| category | string | Only entries of this category: platform, tag_manager, analytics, advertising, marketing_automation, visitor_identification, chat, ab_testing, personalisation, search, external_media, fonts, reviews, payment or security. |  |


```http request
POST https://api.revenexx.com/v1/consent-manager/catalog/adopt
```

** Creates a vendor from a catalogue entry — its fields, its cookies and its purpose links — and records the catalogue key and version it came from. The copy is the tenant's: nothing re-reads the catalogue. Adopting an entry already adopted is refused unless `refresh: true` is sent, which takes the catalogue's current fields and replaces the cookies. A `legal_basis_hint` that differs from the purposes' basis becomes the vendor's `legal_basis_override`. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| key | string | The catalogue key. |  |
| purposes | array | Purpose codes to file the vendor under instead of the catalogue's. |  |
| refresh | boolean | Take the current catalogue entry for a vendor already adopted. |  |


```http request
GET https://api.revenexx.com/v1/consent-manager/cookies
```

** Cookies and storage entries, usually filtered with `?vendor_id=`. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| id | string | Filter to rows whose `id` is exactly this value. The row's own id, generated by the database. A caller never sends one; it reads one back and puts it in the path of later calls. |  |
| vendor_id | string | Filter to rows whose `vendor_id` is exactly this value. The vendor this row belongs to. |  |
| name | string | Filter to rows whose `name` is exactly this value. The cookie or storage key as the browser shows it. |  |
| kind | string | Filter to rows whose `kind` is exactly this value. Where on the device it is stored: cookie, local_storage, session_storage, indexeddb or pixel. |  |
| host | string | Filter to rows whose `host` is exactly this value. Who sets it: 'first-party' for the shop's own domain, otherwise the third-party host. |  |
| position | integer | Filter to rows whose `position` is exactly this value. Where this row sorts in the order a screen and the banner show them, ascending. Presentation only. |  |
| created_at | string | Filter to rows whose `created_at` is exactly this value. When the row was created. Server-set. |  |
| updated_at | string | Filter to rows whose `updated_at` is exactly this value. When the row was last written. Server-set — every route that changes the row stamps it. |  |
| limit | integer | Page size (default 50, max 200). A larger value is clamped. |  |
| offset | integer | Row offset (default 0). |  |
| order | string | Sort by one column: 'column', 'column.asc' or 'column.desc'. |  |

```http request
POST https://api.revenexx.com/v1/consent-manager/defaults
```

** Creates the five standard purposes (necessary, statistics, marketing, comfort, external_media), the shop's banner draft with a German and an English text, and exactly one vendor — `revenexx`, the shop's own necessary cookies — whatever of that is missing, and nothing else. The catalogue is a library: every other vendor, necessary ones included, appears only once the tenant adopts it. Idempotent by code: a purpose or draft the merchant changed is left exactly as it is. The install announcement runs the same seeding, but it is not reliably delivered, so a live check calls this first. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| data | object | Request body |  |

| name | object | What a visitor reads for this purpose. A text per language tag, e.g. { "de": "…", "en": "…" }. |  |
