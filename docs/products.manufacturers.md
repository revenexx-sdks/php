# ProductsManufacturers Service


```http request
GET https://api.revenexx.com/v1/products/manufacturers
```

** A manufacturer is the company a product is made by, kept once and pointed at by every product it makes (`products.manufacturer_id`) instead of repeated as free text on each. It carries what a brand page shows (name, logo, a description per language, website) and what the EU General Product Safety Regulation requires an offer to name: the legal name, postal address and e-mail address of the manufacturer, and for one outside the European Economic Area the responsible person in the EEA. `gpsr_complete` says whether those are all there. A manufacturer is maintained globally — visible in every market — and can be restricted to markets like a category.

Every column of `manufacturers` is an exact-match query parameter, `order` sorts by one column, and `limit`/`offset` page through `page.total`. A query key that is NOT a column is dropped rather than refused, and the `filter` object echoes the ones that were understood — that echo is the only way to tell an unfiltered answer from an empty one. It reads rows exactly as they are stored: no join is resolved, no jsonb value is unpacked.

Records in the trash are left out: `trashed=only` reads the trash itself, `trashed=include` both. Any other value of `trashed` is refused with 400.

Answered from the gateway's tenant cache for up to 30 minutes and dropped the moment this entity is written, because the data model changes weekly at most and every product page asks the same question. **

```http request
POST https://api.revenexx.com/v1/products/manufacturers/migrate
```

** Moves a catalog from the free text `attribute_values.common.manufacturer` to manufacturer records: one record per distinct name (trimmed, whitespace collapsed, case ignored — 'Paul Horn' and 'PAUL HORN' are one), each product linked through `manufacturer_id`. A name an existing record already carries — by name, or by the code it would get — is linked to that record instead of founding a second one. The free text is left where it is.

**Founded records are global and incomplete.** A record the migration founds is assigned to no market — visible in every market, whichever market the caller is working in — and carries only `code` and `name`: no country, so `gpsr_complete` is false until somebody fills in the GPSR data.

**Dry run by default.** Without `"dry_run": false` nothing is written and the answer says what WOULD be created and linked for the products this call walked.

**Chunked and caller-driven**, like a category recompute: a call walks the products that carry no `manufacturer_id` in id order for as long as the gateway budget allows, and answers `done` and, while there is more, the `cursor` to send back. Counts are per call. Idempotent: a product is linked with a compare-and-set on `manufacturer_id` being empty, so one linked by hand in the meantime keeps its link and a second run links nothing twice. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| cursor | string | The `cursor` the previous call answered — a product id — to continue where it stopped. Omitted or null starts at the first product. |  |
| dry_run | boolean | True (the default) writes nothing. False creates the records and links the products. |  |


** Deletes the manufacturers in the trash for good, oldest first, up to 200 per call, each through the same checks as a second `DELETE`. One that is held is reported with its reason and the rest go on; `more` says another call has work left. Refused with 403 for a storefront contact. **


```http request
DELETE https://api.revenexx.com/v1/products/manufacturers/{id}
```

** Moves one manufacturer to the trash — or, called on one that is already there, deletes it for good.

The first call stamps the manufacturer, and nothing goes with it; all of them share one `trash_batch` and come back together on `POST …/{id}/restore`. Nothing that points at it changes: its assignments stay and stop acting, and the answer lists them as warnings with a count. Its code stays reserved while it is in the trash.

The second call deletes it for good, with the rows of its group, and only then do the cascades and `*.deleted` happen. It is refused with 409 while a blocker holds: a switched-on product still made by the manufacturer holds it; any other product is unlinked. A blocker that could not be checked counts as one. It is refused with 403 for a storefront contact — deleting for good is back-office work.

An id no manufacturer of this tenant carries answers 404. **

```http request
GET https://api.revenexx.com/v1/products/manufacturers/{id}/gpsr
```

** Which of the data the EU General Product Safety Regulation (GPSR) requires an online offer to name about its manufacturer this record carries, and which it is missing: the legal name, a postal address with country and an e-mail address, always; and for a manufacturer outside the European Economic Area (EU plus Iceland, Liechtenstein, Norway) the responsible person in the EEA with address and e-mail. The same rule as the stored `gpsr_complete` column, spelled out per field so a form can say what to fill in. It also answers both addresses as an offer prints them (`address_lines`, `eea_responsible_address_lines`), so a product page or a printout shows the lines rather than assembling them. Writes nothing. **
