# MarketingConsentsTypes Service


```http request
GET https://api.revenexx.com/v1/marketing-consents/consent-texts
```

** Every version of every wording, drafts included. Filter by `subscription_type_id` and `locale`. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| id | string | Filter to rows whose `id` is exactly this value. The row's own id, generated by the database. A caller never sends one; it reads one back and puts it in the path of later calls. |  |
| subscription_type_id | string | Filter to rows whose `subscription_type_id` is exactly this value. The subscription type this row belongs to. |  |
| version | integer | Filter to rows whose `version` is exactly this value. The version number within (type, language), counted up by this app on every new draft. |  |
| locale | string | Filter to rows whose `locale` is exactly this value. The language tag the wording is in. |  |
| wording | string | Filter to rows whose `wording` is exactly this value. The exact text a person agrees to, as it appears beside the checkbox. Never changed once published. |  |
| published_at | string | Filter to rows whose `published_at` is exactly this value. When the wording was published. Null is a draft: editable, deletable, and nobody can agree to it. |  |
| published_by | string | Filter to rows whose `published_by` is exactly this value. Who published it, as the platform named the acting person. |  |
| created_at | string | Filter to rows whose `created_at` is exactly this value. When the row was created. Server-set. |  |
| updated_at | string | Filter to rows whose `updated_at` is exactly this value. When the row was last written. Server-set. |  |
| deleted_at | string | Filter to rows whose `deleted_at` is exactly this value. When the record was moved to the trash, or null while it is live. A record in the trash is left out of the list unless `trashed` asks for it, counts nowhere, and is deleted for good by a second DELETE or by the nightly purge. |  |
| deleted_by | string | Filter to rows whose `deleted_by` is exactly this value. Who moved it to the trash, as the platform named them — an email, or `system`. Null while it is live. |  |
| deleted_by_id | string | Filter to rows whose `deleted_by_id` is exactly this value. The platform subject of whoever moved it to the trash. Kept beside the name so the person can be pseudonymised later without losing who acted. Null while it is live. |  |
| trash_batch | string | Filter to rows whose `trash_batch` is exactly this value. The trash action this record went with. A restore brings back exactly the records that carry it. |  |
| purge_at | string | Filter to rows whose `purge_at` is exactly this value. When the nightly purge deletes it for good unless it is restored first: `deleted_at` plus the tenant's trash retention (90 days unless the tenant says otherwise). Null while it is live. |  |
| purge_blocked_reason | string | Filter to rows whose `purge_blocked_reason` is exactly this value. Why the purge could not delete it for good. Null when nothing stopped it. Cleared by a restore. |  |
| trashed | string | `exclude` (default) leaves the trash out, `only` is the trash itself, `include` lists both. |  |
| limit | integer | Page size (default 50, max 200). A larger value is clamped. |  |
| offset | integer | Row offset (default 0). |  |
| order | string | Sort by one column: 'column', 'column.asc' or 'column.desc'. |  |

```http request
POST https://api.revenexx.com/v1/marketing-consents/consent-texts/trash/empty
```

** Every consent text in the trash is deleted for good on its own terms. One that something still blocks stays in the trash and is named with its reason, so a partial success says exactly what remained. Not for a storefront contact. **


```http request
POST https://api.revenexx.com/v1/marketing-consents/consent-texts/trash/purge
```

** What the nightly purge does, callable by hand: every consent text in the trash for longer than the tenant trash retention (90 days unless the tenant set another) is deleted for good through the same rules as a second delete. A blocked one stays and carries its reason. When the retention cannot be read, nothing is deleted. Also the cron schedule. **


```http request
DELETE https://api.revenexx.com/v1/marketing-consents/consent-texts/{id}
```

** The first DELETE moves the consent text into the trash: it stays, with everything hanging off it, and counts nowhere until it is restored. Only a draft goes in; a published version is proof and is refused (`trash_blocked`, blocker `text_published`). A draft whose type is in the trash comes back only after the type (`parent_in_trash`). A DELETE on a consent text already in the trash deletes it for good — refused while something still needs it, and not for a storefront contact. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| id | string | **Required** The consent text. |  |

```http request
POST https://api.revenexx.com/v1/marketing-consents/subscription-types
```

** A new purpose to write about. `code` and `labels` are owed; it needs a published consent text before anybody can sign up. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| allows_existing_customer | boolean | Whether a placed order may open the existing-customer basis of §7 (3) UWG for this type. Needs `similar_goods_note`. Defaults to false. |  |
| channels | array | The channels this type is offered by, drawn from email, sms and whatsapp. A subscription holds exactly one of them. Defaults to ["email"] on create. |  |
| code | string | The type's fixed identity, named by every mailing, journey step, eligibility call and bus event. Lowercase letters, digits and '_'; never changes once created. Sent on create only; an update may repeat it unchanged. |  |
| descriptions | object | The sentence under the type in the preference centre — what and how often. A text per language tag, e.g. { "de": "…", "en": "…" }. |  |
| labels | object | What a recipient reads for the type in the preference centre and the confirmation mail. A text per language tag, e.g. { "de": "…", "en": "…" }. |  |
| position | integer | Where this row sorts in lists and in the preference centre, ascending. Presentation only. |  |
| requires_doi | boolean | Whether a sign-up waits for the confirmation click (double opt-in). Off confirms at once on the single-opt-in basis, which is weaker proof. Defaults to true. |  |
| similar_goods_note | object | Which of the merchant's own similar goods this type advertises — the condition the existing-customer basis rests on. A text per language tag, e.g. { "de": "…", "en": "…" }. |  |
