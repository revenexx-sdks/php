# ConsentManagerPolicy Service


```http request
GET https://api.revenexx.com/v1/consent-manager/banner
```

** The draft for the market in `x-revenexx-market`. A market without its own answers the shop's draft with `inherited: true`. A tenant with no draft at all gets the default one created. **


```http request
PUT https://api.revenexx.com/v1/consent-manager/banner
```

** Save the draft for the market in `x-revenexx-market` ('' = the shop). A market's first save starts from a copy of the shop's draft. Nothing a visitor sees changes until the next publish. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| imprint_url | string | The shop's imprint, linked from the first layer. |  |
| layout | string | The layout this draft asks for — box, bar or modal — or null to follow the `banner_layout` setting. |  |
| privacy_url | string | The shop's privacy policy, linked from the first layer. |  |
| texts | object | The banner's labels per language: { "de": { "title": …, "body": …, "accept_all": …, "reject_all": …, "settings": …, "save": … } }. Required per language before publishing: title, body, accept_all, reject_all, settings, save. Optional: preferences_title, preferences_body, object, load_once, gate_text, privacy_link, cookie_details, always_active, close. |  |


```http request
GET https://api.revenexx.com/v1/consent-manager/policy-versions
```

** Every published version. There is no route that edits or deletes one — both answer 405 — because a version is the evidence of what visitors read. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| id | string | Filter to rows whose `id` is exactly this value. The row's own id, generated by the database. A caller never sends one; it reads one back and puts it in the path of later calls. |  |
| number | integer | Filter to rows whose `number` is exactly this value. The version's number. It rises with every publish across what the publishing call can see, and the visitor's cookie remembers the number it was asked under. |  |
| market | string | Filter to rows whose `market` is exactly this value. The market this row belongs to, by code — '' (empty) is the shop as a whole. Taken from the `x-revenexx-market` header of the call that wrote it, never from a body. |  |
| material | boolean | Filter to rows whose `material` is exactly this value. Whether this publish asks every visitor again. Set by the publish, or forced on by the `reconsent_on_publish` setting. |  |
| material_number | integer | Filter to rows whose `material_number` is exactly this value. The number of the latest material version up to and including this one. A storefront asks again when the number in the visitor's cookie is lower. |  |
| sha256 | string | Filter to rows whose `sha256` is exactly this value. SHA-256 over the canonical JSON of `content` (object keys sorted, recursively). Recomputing it proves the content has not moved since it was published. |  |
| note | string | Filter to rows whose `note` is exactly this value. What changed, in the publisher's words. Optional. |  |
| published_at | string | Filter to rows whose `published_at` is exactly this value. When the version was published. Server time. |  |
| published_by | string | Filter to rows whose `published_by` is exactly this value. The subject of the identity that published it, when the call carried one. |  |
| created_at | string | Filter to rows whose `created_at` is exactly this value. When the row was created. Server-set. |  |
| limit | integer | Page size (default 50, max 200). A larger value is clamped. |  |
| offset | integer | Row offset (default 0). |  |
| order | string | Sort by one column: 'column', 'column.asc' or 'column.desc'. |  |


```http request

```

** One version with its full frozen content and hash. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| id | string | **Required** The version. |  |


```http request
POST https://api.revenexx.com/v1/consent-manager/policy/preview
```

** Renders the draft exactly as publishing would, without publishing it, and answers a token that reads it at GET /consent-manager/delivery/preview/{token} until it expires (72 hours by default, at most 168). The same refusals as a publish apply. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| ttl_hours | integer | How long the token answers. |  |


```http request
POST https://api.revenexx.com/v1/consent-manager/policy/publish
```

** Renders the draft, the active purposes and vendors and the settings in every language the draft speaks, and stores them as a new immutable version with a SHA-256 hash over the canonical content. The version is for the market in `x-revenexx-market` ('' = the shop). `material: false` keeps visitors' earlier decisions valid — unless the `reconsent_on_publish` setting is `always`, or there is no earlier version. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| material | boolean | Whether visitors are asked again. Defaults to true. |  |
| note | string | What changed. |  |
