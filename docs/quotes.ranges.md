# QuotesRanges Service


```http request
GET https://api.revenexx.com/v1/quotes/number-ranges
```

** The counters quote numbers are drawn from. A market points at one by its `code`; the app seeds `quote` with the prefix `ANG-`. Every range is listed, switched off or not, unless `active` asks for one kind. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| limit | integer | Page size (default 50, max 200). A larger value is clamped rather than refused. |  |
| offset | integer | Row offset for pagination (default 0). Page with `page.total` and `page.hasMore`. |  |
| order | string | Sort by one column: 'column' | 'column.asc' | 'column.desc'. The column has to be one this entity has. |  |
| active | boolean | Only the ranges that are switched on (`true`) or off (`false`). Omitted lists both. |  |


```http request
POST https://api.revenexx.com/v1/quotes/number-ranges
```

** Adds a counter, so one market can number its quotes differently from another. The code is unique per tenant. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| active | boolean | Whether quote numbers may be drawn from this range. True by default. A quote that would draw from an inactive range is refused with 422 `number_range_inactive` — never recreated or drawn from another range. Numbers already issued stay, and seeding never switches a range back on. |  |
| code | string | What a market points at to draw from this range. Unique per tenant; `quote` is the one this app seeds. |  |
| counter | integer | The last number drawn. The next draw adds `step` and stores the result, so a number is never handed out twice. |  |
| created_at | string | When the row was written, stamped by the database. |  |
| id | string | The row's own id, generated by the database. A caller never sends one — it reads one back and puts it in the path of every later call. |  |
| labels | object | The name per locale, keyed by locale code, e.g. `{"de": "Angebotsnummern", "en": "Quote numbers"}`. Falls back to `title` for a locale that is missing. A standard range created before names existed is given them by the next seed or draw; a name already there is never overwritten. |  |
| padding | integer | How many digits the counter is padded to. 6 gives `000001`. |  |
| position_step | integer | How far apart position numbers sit on a new quote — 10 leaves room to insert a line later without renumbering. |  |
| prefix | string | Put in front of the counter — `ANG-` produces `ANG-000001`. |  |
| step | integer | How far the counter moves per draw. 1 is consecutive; a larger step leaves gaps on purpose. |  |
| suffix | string | Put after the counter. Empty on the standard range. |  |
| tenant_id | string | The tenant this row belongs to. Set by the data plane from the request identity and never accepted from a caller. |  |
| title | string | The range's name, what a list and a breadcrumb show: the fallback for every locale `labels` does not carry. The standard `quote` range is named `Quote numbers`; a range of the merchant's own has none until they give it one, and a screen shows the code instead. |  |
| updated_at | string | When the row last changed, stamped by the app on every write. |  |


```http request
POST https://api.revenexx.com/v1/quotes/number-ranges/defaults
```

** Creates the `quote` range if it is missing. Idempotent, and what an integration calls first — the install event does not reliably fire on a marketplace install. A range that exists is left as it is, so one a merchant switched off stays off. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| library | array | The reusable blocks to create. Idempotent by label among live items. One without a label or without a block tree is reported under `skipped`. |  |
| menus | array | The menus to create. One with no key or no label is reported under `skipped`. |  |
| mode | string | `fill` (the default) adds what is missing and keeps everything that exists. `reset` replaces every section that is sent — pages, menus and library items go to the trash first, site settings are removed — and must be asked for by name. |  |
| pages | array | The pages to create. One that has no `slug` or no `title` is reported under `skipped` rather than refused, so one bad entry never loses the rest. |  |
| settings | object | Site settings by key — the same values `PUT /pages/settings/site/{key}` stores. In fill only keys the tenant has not set are written; in reset every existing key is removed first. A key that is not a valid setting name, an empty value or one over 128 KiB is reported under `skipped`. |  |


```http request
DELETE https://api.revenexx.com/v1/quotes/number-ranges/{id}
```

** Removes a counter. The standard one comes back on the next draw rather than breaking quoting. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| id | string | **Required** The number range. |  |
