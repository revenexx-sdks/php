# ConsentManagerRecords Service


```http request
GET https://api.revenexx.com/v1/consent-manager/records
```

** Every record, filterable by column. There is no route that edits one — an update answers 405. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| id | string | Filter to rows whose `id` is exactly this value. The row's own id, generated by the database. A caller never sends one; it reads one back and puts it in the path of later calls. |  |
| consent_id | string | Filter to rows whose `consent_id` is exactly this value. The random uuid v4 in the visitor's own `rvx_consent` cookie. It chains one browser's decisions and nothing else — it is never handed to a tag, and a full withdrawal mints a new one. |  |
| action | string | Filter to rows whose `action` is exactly this value. What the visitor did: accept_all, reject_all, custom, vendor_grant, withdraw or renew. |  |
| surface | string | Filter to rows whose `surface` is exactly this value. Where they did it: first_layer, preferences, privacy_link or content_gate. |  |
| policy_version_id | string | Filter to rows whose `policy_version_id` is exactly this value. The published version the visitor was shown. |  |
| policy_number | integer | Filter to rows whose `policy_number` is exactly this value. That version's number. |  |
| policy_sha256 | string | Filter to rows whose `policy_sha256` is exactly this value. That version's hash, copied in, so the record alone proves which text it points at. |  |
| locale | string | Filter to rows whose `locale` is exactly this value. The language the visitor was shown. |  |
| market | string | Filter to rows whose `market` is exactly this value. The market this row belongs to, by code — '' (empty) is the shop as a whole. Taken from the `x-revenexx-market` header of the call that wrote it, never from a body. |  |
| recorded_at | string | Filter to rows whose `recorded_at` is exactly this value. When the server received the decision. This is the authoritative time. |  |
| client_ts | string | Filter to rows whose `client_ts` is exactly this value. The visitor's clock when they decided, kept as a hint — a record retried on a later page view carries it. |  |
| expires_at | string | Filter to rows whose `expires_at` is exactly this value. When the decision lapses: the received time plus the version's consent lifetime. Retention of the newest record counts from here. |  |
| user_agent_class | string | Filter to rows whose `user_agent_class` is exactly this value. The browser family and major version only — never the full user agent. |  |
| page_path | string | Filter to rows whose `page_path` is exactly this value. The path the decision was made on, without query or fragment, so no campaign id is ever stored. |  |
| contact_id | string | Filter to rows whose `contact_id` is exactly this value. The signed-in B2B contact, taken from the identity the gateway injected — never from the body. Set to null on an erasure request; the rest of the record stays. |  |
| created_at | string | Filter to rows whose `created_at` is exactly this value. When the row was created. Server-set. |  |
| limit | integer | Page size (default 50, max 200). A larger value is clamped. |  |
| offset | integer | Row offset (default 0). |  |
| order | string | Sort by one column: 'column', 'column.asc' or 'column.desc'. |  |


```http request
POST https://api.revenexx.com/v1/consent-manager/records
```

** Stores one decision under the version that was shown. Every purpose of that version is stored explicitly — a consent purpose left out is denied. The contact comes from the identity the gateway injected, never from the body. No IP address, full user agent or query string is stored, whatever the request carries. Two identical decisions in a row under one version answer the existing record with 200 and `deduplicated: true`. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| action | string | What the visitor did: accept_all, reject_all, custom, vendor_grant, withdraw or renew. |  |
| client_ts | string | The visitor's clock when they decided, kept as a hint — a record retried on a later page view carries it. |  |
| consent_id | string | The random uuid v4 in the visitor's own `rvx_consent` cookie. It chains one browser's decisions and nothing else — it is never handed to a tag, and a full withdrawal mints a new one. |  |
| decisions | object | What was decided. Purposes and vendors by code, each granted, denied or objected. A consent purpose left out is stored denied. |  |
| locale | string | The language the visitor was shown; one the version holds. |  |
| page_path | string | The page the decision was made on. Any query or fragment is cut off before storing. |  |
| policy_version_id | string | The published version the visitor was shown. |  |
| surface | string | Where they did it: first_layer, preferences, privacy_link or content_gate. |  |
| user_agent_class | string | The browser as family and major version. A longer value is reduced to that; a full user agent is never stored. |  |


```http request
GET https://api.revenexx.com/v1/consent-manager/records/by-consent/{consent_id}
```

** Every record of one consent id, oldest first, each naming the version it was shown under. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| consent_id | string | **Required** The consent id from the visitor's cookie. |  |


```http request
GET https://api.revenexx.com/v1/consent-manager/records/export
```

** The records received from `from` (inclusive) to `to` (exclusive), oldest first, as rows and as one CSV rendering. Every row names the version and hash it points to. At most 1000 rows per call; continue with `next_offset`. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| from | string | Start of the period, inclusive. |  |
| to | string | End of the period, exclusive. |  |
| market | string | Only this market ('' = the shop). |  |
| limit | integer | Rows per call (max 1000). |  |
| offset | integer | Continue from here. |  |


```http request
POST https://api.revenexx.com/v1/consent-manager/records/prune
```

** Deletes records that ended longer ago than `proof_retention_days` (never less than 365): superseded records from the time the same browser decided again, the newest one from its expiry. The newest record of a browser therefore stays while it is current. Previews unless `dry_run: false` is sent; the daily `prune-records` schedule runs it for real. Bounded per call — `has_more` says whether to call again. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| dry_run | boolean | Defaults to true: report, delete nothing. |  |


```http request
GET https://api.revenexx.com/v1/consent-manager/records/summary
```

** Granted, denied and objected counts per purpose and counts per action for one market (`?market=`, else `x-revenexx-market`, else the shop) and an optional period. A statistic: it carries no consent id, record id or contact. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| market | string | The market ('' = the shop). |  |
| from | string | Start, inclusive. |  |
| to | string | End, exclusive. |  |


```http request
POST https://api.revenexx.com/v1/consent-manager/records/unlink-contact
```

** An erasure request for a signed-in contact: sets `contact_id` to null on every record of that contact and changes nothing else. The proof stays, because it is kept for legal claims (Art. 17 (3) e GDPR). The only mutation a record ever sees. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| contact_id | string | The contact to unlink. |  |
