# MarketingConsentsSubscriptions Service


```http request
POST https://api.revenexx.com/v1/marketing-consents/confirm/{token}
```

** The double opt-in click, called by the storefront's confirmation page. Turns the pending subscription confirmed on the consent_doi basis and writes the proof with the person's IP and browser. A second click answers the same without writing anything. An expired link lapses the sign-up. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| token | string | **Required** The token from the confirmation message. |  |
| allocations | array | Optional: the request's allocations (the reserve's shape; an empty array is the same as none, and only cost_center_id is read), used only to classify its cost centres by budget type. A request holding no reservation whose every centre is tracking-only is then settled with nothing written; one naming a monetary centre, or naming none, is refused with 409 as before. Amounts are read from the ledger, never from here. |  |
| currency | string | ISO 4217 code the amount is stated in. Omit to be read in the cost centre's (or the personal limit's) own currency; a code that differs from it is refused with 409 currency_mismatch. |  |
| note | string |  |  |
| order_id | string |  |  |
| purchase_request_id | string |  |  |


```http request
POST https://api.revenexx.com/v1/marketing-consents/eligibility
```

** The one call `mailings` and `journeys` make before every batch. Per recipient: allowed or not, with the legal basis or the reason. Only a confirmed subscription allows; `contract` never does; `existing_customer` only on a type that allows it; an erased address answers `erased`. At most 500 recipients per call. The sequencer's suppression stays the last refusal at send time. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| channel | string | Defaults to email. |  |
| recipients | array | Up to 500 recipients. |  |
| subscription_type | string | The code of the type the send is under. |  |

```http request
POST https://api.revenexx.com/v1/marketing-consents/preferences/{token}
```

** Per type: `subscribed: false` withdraws at once (source preference_centre, pushed to the sequencer); `subscribed: true` signs up — with a confirmation first when the type requires double opt-in. `unsubscribe_all: true` withdraws every type of the channel. Answers the page as it now stands, with what changed. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| token | string | **Required** The personal token. |  |
| choices | array | The choices. |  |
| ip | string | The person's IP address. |  |
| locale | string | The language of the page. |  |
| unsubscribe_all | boolean | Withdraw every type of the channel. |  |
| user_agent | string | The person's browser. |  |


```http request
GET https://api.revenexx.com/v1/marketing-consents/subscriptions
```

** Every subscription. Filter by `subscription_type_id`, `state`, `channel`, `contact_id`, `address`. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| id | string | Filter to rows whose `id` is exactly this value. The row's own id, generated by the database. A caller never sends one; it reads one back and puts it in the path of later calls. |  |
| contact_id | string | Filter to rows whose `contact_id` is exactly this value. The `customers` contact holding the address. Null until one exists — a sign-up creates one at lifecycle stage `subscriber` — and after an erasure. |  |
| channel | string | Filter to rows whose `channel` is exactly this value. How the address is reached: email, sms or whatsapp. |  |
| address | string | Filter to rows whose `address` is exactly this value. The address: a lower-cased email or an E.164 phone number. Null after an erasure. |  |
| address_hash | string | Filter to rows whose `address_hash` is exactly this value. SHA-256 of the normalised address, hex. Every lookup goes through it, and it is the only part of the address an erasure keeps. |  |
| subscription_type_id | string | Filter to rows whose `subscription_type_id` is exactly this value. The subscription type this row belongs to. |  |
| state | string | Filter to rows whose `state` is exactly this value. Where the subscription stands: pending (waiting for the click), confirmed, withdrawn or lapsed (the click never came). Only confirmed can make a send allowed. |  |
| legal_basis | string | Filter to rows whose `legal_basis` is exactly this value. Why a send is allowed: consent_doi (double opt-in), consent_single (imported single opt-in, weaker proof), existing_customer (§7 (3) UWG) or contract (never a basis for advertising). |  |
| consent_text_id | string | Filter to rows whose `consent_text_id` is exactly this value. The published consent text — wording and version — the person agreed to. Null for the existing-customer basis and for imports, which saw no wording. |  |
| locale | string | Filter to rows whose `locale` is exactly this value. The language of the sign-up, used for the confirmation mail and the preference centre. |  |
| market | string | Filter to rows whose `market` is exactly this value. The market code the row was written in, taken from `x-revenexx-market`; '' is the shop as a whole. |  |
| campaign_ref | string | Filter to rows whose `campaign_ref` is exactly this value. The campaign the sign-up came from, as the caller named it (a campaigns id). Attribution only. |  |
| source | string | Filter to rows whose `source` is exactly this value. Where it came from: form, storefront (a shop sign-up box), import, admin, unsubscribe_header (RFC 8058 one-click), preference_centre, order, complaint (a spam report) — and, on events only, system (the lapse job). |  |
| source_ref | string | Filter to rows whose `source_ref` is exactly this value. What exactly it came from: a form id, an order id, a message id, an import id. |  |
| requested_at | string | Filter to rows whose `requested_at` is exactly this value. When the latest sign-up for this address and type arrived. |  |
| confirmation_sent_at | string | Filter to rows whose `confirmation_sent_at` is exactly this value. When the sequencer accepted the confirmation message. Null while none went out — the sign-up stands, the person can ask again. |  |
| confirmed_at | string | Filter to rows whose `confirmed_at` is exactly this value. When the subscription became confirmed: the click, an order (existing customer), an import, or the sign-up itself on a type without double opt-in. |  |
| withdrawn_at | string | Filter to rows whose `withdrawn_at` is exactly this value. When it was withdrawn. |  |
| lapse_at | string | Filter to rows whose `lapse_at` is exactly this value. When a pending sign-up lapses if nobody clicks. |  |
| erased_at | string | Filter to rows whose `erased_at` is exactly this value. When the address was erased on request. The row keeps type, basis, times and the address hash. |  |
| suppression_written_at | string | Filter to rows whose `suppression_written_at` is exactly this value. When the sequencer's suppression received the withdrawal. Null on a withdrawn row means the hourly job will try again. |  |
| suppression_ref | string | Filter to rows whose `suppression_ref` is exactly this value. The id of the suppression this app wrote into the sequencer for the withdrawal, so the sweep can tell this app's own rows from unsubscribes it has to act on. |  |
| external_id | string | Filter to rows whose `external_id` is exactly this value. The key of this record in the system that leads it — a marketing tool, an ERP, an ad platform. Unique per tenant when set; an import matches on it. |  |
| source_synced_at | string | Filter to rows whose `source_synced_at` is exactly this value. When a sync last wrote this record from its source system. Null for a record only ever kept here. |  |
| created_at | string | Filter to rows whose `created_at` is exactly this value. When the row was created. Server-set. |  |
| updated_at | string | Filter to rows whose `updated_at` is exactly this value. When the row was last written. Server-set. |  |
| limit | integer | Page size (default 50, max 200). A larger value is clamped. |  |
| offset | integer | Row offset (default 0). |  |
| order | string | Sort by one column: 'column', 'column.asc' or 'column.desc'. |  |


```http request
POST https://api.revenexx.com/v1/marketing-consents/subscriptions/request
```

** Used by the forms listener and the storefront. Opens (or reopens) a pending subscription, creates the `customers` contact when the address has none (stage `subscriber`), writes the `requested` proof and asks the sequencer for the advertising-free confirmation. The token is in that message only — never in this answer. A confirmed address is answered as it is; a pending one asked again within ten minutes gets no second mail. A type without double opt-in is confirmed at once on the single-opt-in basis. **

### Parameters

| Field Name | Type | Description | Default |
| --- | --- | --- | --- |
| address | string | Alias for `email` or `phone`, whichever the channel takes. |  |
| campaign_ref | string | The campaign the sign-up came from, as the caller named it (a campaigns id). Attribution only. |  |
| channel | string | Defaults to email, or sms when only `phone` is sent. |  |
| consent_text_id | string | The published wording the person saw. Without it the newest published version of the type in `locale` is recorded. |  |
| contact_id | string | The contact, when the caller knows it (a signed-in buyer). Skips the lookup. |  |
| email | string | The email address (email channel). |  |
| first_name | string | For a new contact. |  |
| ip | string | The person's IP address, as the storefront saw it. |  |
| last_name | string | For a new contact. |  |
| locale | string | The language of the sign-up (default de). |  |
| page_url | string | The page the sign-up was made on. |  |
| phone | string | The phone number in international form (sms, whatsapp). |  |
| source | string | Where the sign-up was made (default storefront). |  |
| source_ref | string | What exactly it came from: a form id, an order id, a message id, an import id. |  |
| subscription_type | string | The code of the subscription type. |  |
| user_agent | string | The person's browser. |  |
